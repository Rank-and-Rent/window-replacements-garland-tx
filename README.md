# Window Replacement Service of Garland

Premium window replacement website for Garland, TX featuring Andersen, Pella, and Jeld-Wen windows.

## Getting Started

1. Install dependencies:

```bash
npm install
```

2. Run the development server:

```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Features

- **Window Types**: Double-Hung, Single-Hung, Casement, Awning, Sliding, Picture, Bay & Bow, Special Shape
- **Premium Brands**: Andersen, Pella, Jeld-Wen
- **Location**: 350 Oaks Trl #220, Garland, TX 75043
